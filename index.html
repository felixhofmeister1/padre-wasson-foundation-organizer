        How to set up WordPress access
        1. In WordPress, open Users → Profile and scroll to Application Passwords (WordPress 5.6+).
        2. Enter a name such as “Foundation Organizer”, click Add New Application Password and paste the generated password above. Use your normal WordPress username.
        3. The site must run on HTTPS, and the user needs at least the Author role to create posts and upload files.
        4. Large videos can be bigger than the server's upload limit (often 8–64 MB). Those files will show an error and the rest still upload.
        5. If the test fails with a network error, a security plugin or firewall may be blocking the REST API or cross-origin requests. Use Copy as cURL to upload from a terminal instead.
